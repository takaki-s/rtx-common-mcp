# Yamaha RTX Command Reference - URL & Content Structure

The Yamaha RTX (RT-Common) manual is organized as a framed web application.

## 1. Base URL
`https://www.rtpro.yamaha.co.jp/RT/manual/rt-common/`

## 2. Core Navigation Pages
- **Index (Frameset)**: `index.html` (root)
- **Table of Contents (TOC)**: `toc.html`
    - Contains a hierarchical list of chapters and commands.
    - Commands are organized by category/function (e.g., Interface, IP, Security).
    - Best for browsing functional groups.
- **Alphabetical Command Index**: `cmdref_index.html`
    - Contains a flat, exhaustive list of all commands mapped to their exact CLI syntax.
    - Structure: `<li><a href=category/file.html>exact command name</a>`
    - Best for resolving a command string (e.g., "ip route") to its reference page.

## 3. Command Page URL Pattern
Commands are stored in subdirectories based on their functional category.
- **Pattern**: `[category_slug]/[command_filename].html`
- **Examples**:
    - `showstatus/show_ip_route.html` (IP route table status)
    - `operation/ping.html` (Ping command)
    - `setup/login_password.html` (Login password configuration)
    - `showconfig/show_config.html` (Show current configuration)

## 4. Page Content Structure (DITA-generated)
The command pages follow a consistent structure generated by DITA (Darwin Information Typing Architecture).

### Key Selectors for Parsing:
- **Command Name**: `h1.title`
- **Syntax (書式)**:
    - Title: `.section.title:contains("書式")` or `h2.sectiontitle:contains("書式")`
    - Content: Next `ul.sl.simple` (for structured syntax) or `.pre.codeblock` / `.pre`.
- **Description (説明)**:
    - Title: `.section.title:contains("説明")` or `h2.sectiontitle:contains("説明")`
    - Content: Next `div` or internal `p` tags.
- **Parameters & Default Values (設定値及び初期値)**:
    - Title: `h2.sectiontitle` containing "設定値" or "パラメータ".
    - Often combined with "初期値" (Default values).
    - Content: Following `li.li` elements or a `table`.
- **Examples (例)**:
    - Title: `h2.sectiontitle:contains("例")`
    - Content: Following `.pre.codeblock`.

## 5. Technical Details
- **Encoding**: UTF-8 (Current manual version).
- **Target Frame**: All links in the TOC and Index specify `target="contentwin"`.
